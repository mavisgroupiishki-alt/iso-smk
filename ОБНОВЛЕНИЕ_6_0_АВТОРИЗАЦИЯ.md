# Обновление MAVIS Task Tracker до версии 6.0

## Что изменилось

- Вход по логину и паролю.
- Приложение определяет сотрудника по его профилю Supabase.
- Аня — администратор.
- Только Аня создаёт и редактирует разделы и сотрудников.
- При добавлении сотрудника задаются имя, должность, логин, пароль, цвет и норма активных задач.
- Перегруз сотрудника подсвечивается в приложении.
- Добавлен график «Активные задачи против нормы».

## Порядок обновления

### 1. Резервная копия

В действующем приложении нажмите «Резервная копия».

### 2. Создайте первую учётную запись Ани

В Supabase откройте:

`Authentication → Users → Add user`

Укажите:

- Email: `anya@mavis.local`
- Password: придумайте пароль Ани минимум из 8 символов
- Auto Confirm User: включено

Email технический. В самом приложении Аня будет входить логином `Аня`.

### 3. Выполните SQL

Откройте:

`SQL Editor → New query`

Вставьте весь файл `supabase_v6_auth_overload.sql` и нажмите `Run`.

В результате должно быть:

- `anya_admin_ready = true`
- `capacity_ready = true`

Количество проектов и задач не должно уменьшиться.

### 4. Создайте Edge Function

В Supabase откройте:

`Edge Functions → Deploy a new function → Via Editor`

Название функции:

`admin-manage-user`

Вставьте код из:

`supabase/functions/admin-manage-user/index.ts`

Нажмите Deploy.

Функция нужна, потому что пароль и создание Auth-пользователя нельзя безопасно выполнять прямо в браузере.

### 5. Загрузите приложение

Распакуйте ZIP версии 6.0 и загрузите его содержимое в корень GitHub с заменой старых файлов.

В Render выполните:

`Manual Deploy → Deploy latest commit`

После статуса `Live` обновите страницу через `Cmd + Shift + R`.

### 6. Первый вход

- Логин: `Аня`
- Пароль: пароль, заданный в Supabase Authentication

После входа откройте вкладку «Команда» и создайте учётные записи остальных сотрудников.

## Как работает перегруз

Для каждого сотрудника указывается «Норма активных задач».

- до нормы — обычная карточка;
- выше нормы — жёлтая подсветка;
- выше нормы более чем на 25% — красная подсветка;
- сверху приложения появляется общее предупреждение о перегрузе команды.

Завершённые задачи в загрузку не входят.
