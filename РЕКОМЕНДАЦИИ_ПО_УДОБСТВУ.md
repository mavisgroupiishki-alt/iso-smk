# Рекомендации по дальнейшему развитию

## Уже учтено в этой версии

- основная иерархия: раздел → проект → этап → задача;
- проекты без раздела собраны в отдельный блок, чтобы ничего не потерялось;
- задачи проекта без этапа также отображаются отдельно;
- в каждом разделе по умолчанию показываются только активные задачи;
- у каждого раздела есть отдельный фильтр по статусам;
- есть единая кнопка сброса всех общих фильтров;
- загрузка команды рассчитывается по количеству активных задач, а не по часам;
- в команде отдельно видны активные, просроченные и все задачи.

## Что рекомендую добавить следующим этапом

1. **Архив проектов.** Завершённые проекты не удалять, а переносить в отдельный архив.
2. **Сохранённые наборы фильтров.** Например: «Мои активные на неделю», «Просроченные Тани», «На проверке».
3. **Порядок разделов и проектов.** Перетаскивание мышкой для изменения очередности.
4. **Шаблоны проектов.** Создание типового проекта сразу с готовыми этапами и задачами.
5. **Регулярные задачи.** Автоматическое создание еженедельных и ежемесячных задач.
6. **Индикатор здоровья проекта.** Просрочки, блокеры, количество переносов и ближайший критический срок.
7. **Журнал действий.** Кто изменил статус, ответственного, комментарий или структуру проекта.
8. **Вход сотрудников и права.** Руководитель видит всё, сотрудник — свои задачи и проекты, заказчик — только нужные проекты.
9. **Уведомления.** Напоминания о сроках, новых комментариях, блокерах и переносах.
10. **Массовые действия.** Выделить несколько задач и сразу поменять ответственного, статус, дату или этап.
