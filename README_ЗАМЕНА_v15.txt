ОСНОВНЫЕ ИСПРАВЛЕНИЯ

1) ISO / СУОТ теперь формируется по фактическому штату:
- ИТР -> должностные инструкции;
- рабочие -> инструкции по охране труда по профессиям;
- внутренние аудиты -> фактические ИТР-должности + пункты аудита;
- лишние должностные инструкции и карточки рисков по отсутствующим ролям исключаются.

2) Область сертификации:
- certification.scope имеет приоритет над старым company.scope;
- в отчёты вставляется только область текущего пакета;
- SUOT-отчёты, где раньше поля области вообще не было, получают отдельную строку «Область применения».

3) Текущая организация:
- заменяется во всех word/*.xml частях, включая колонтитулы;
- удалены остаточные маркеры [Наименование] и [Форма_собственности_сокращенная];
- «Варта» не остаётся ни в содержимом, ни в именах файлов.

4) Штат в исходной информации:
- численность сотрудников рассчитывается по текущей карточке;
- совместители/неполная занятость считаются по employment_type/part_time;
- старые фиксированные значения шаблона не используются.

5) Поставщики:
- старые карточки поставщиков «Варты» больше не копируются;
- карточки создаются по фактическому списку suppliers;
- неизвестные оценки остаются «ТРЕБУЕТ УТОЧНЕНИЯ» и выделяются жёлтым.

6) Аттестация компании / Форма №2:
- данные ИТР из общего staff (образование, дипломы, трудовые, периоды стажа, аттестаты)
  подмешиваются в company_attestation.itr по ФИО, поэтому уже известные данные не превращаются
  в ложное «ТРЕБУЕТ УТОЧНЕНИЯ».
- сам стаж по-прежнему рассчитывается по трудовой; при отсутствии точных периодов он честно остаётся жёлтым.

7) Ошибка «ИИгорь сказал, что исправил, но ничего не поменял»:
- интерфейс сравнивает карточку до и после правки;
- если структурированные данные не изменились, выполняется одна контрольная попытка;
- если изменение всё равно не применено, ИИгорь прямо пишет, что правка НЕ применена,
  и больше не говорит «всё исправил/готово».
- подтверждение обучения больше не обещает, что Word-шаблон уже изменён без проверки нового пакета.

8) Скорость ISO / СУОТ:
- для ISO/SUOT используется отдельный компактный системный промпт;
- архив не запускает отдельный AI-вызов на каждого сотрудника;
- для скан-PDF в ISO/SUOT распознаются максимум первые 2 страницы одного документа
  (обычно удостоверение занимает 1 страницу);
- полный исходный архив сохраняется для кнопки «Проверить исходный архив», а в ИИ передаётся
  сокращённый продуктовый контекст;
- старый AI-per-document fallback полностью отключён для ISO/SUOT: ошибка теперь видна сразу,
  а не приводит к 20–30 минутам скрытой генерации.
