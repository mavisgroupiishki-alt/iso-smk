Что установлено:
- Полный справочник «вид работ 7.* → профессии рабочих» из файла
  «ОБРАЗЕЦ Сведения о рабочих (15).docx».
- Охвачены: основания, фундаменты, строительные конструкции, антикоррозия,
  кровли, фасады, внутренние и наружные сантехнические сети, вентиляция,
  газоснабжение, внутреннее и наружное электроснабжение, связь/сигнализация,
  автоматизация, холодоснабжение, технологические трубопроводы, теплоизоляция,
  дороги и благоустройство.
- При выборе родительского пункта (например 7.8, 7.19 или 7.24) автоматически
  учитываются все его подпункты.
- Одинаковые профессии не дублируются.
- Если у одной профессии есть несколько разрядов, в Форме №2 она выводится одной
  строкой с количеством по каждой колонке II–VI.
- Готовая загруженная Форма №2 остаётся источником истины и не расширяется
  автоматическим стандартом.
- Ручная правка может уменьшать количество и имеет приоритет над автоподстановкой.
- ИИ не должен запрашивать штатное расписание/трудовые книжки только для первичного
  заполнения рабочих.

Стандарт количества и разряда:
- Для общестроя без фасадов и с фасадами используются точные таблицы с разрядами и
  количеством из страниц 4–5 предоставленного образца.
- Для видов работ, где в образце указаны профессии, но не указаны разряд и количество,
  приложение ставит редактируемый стандарт: III разряд, 1 человек.

Проверка:
- Python-файлы успешно прошли py_compile.
- JavaScript успешно прошёл node --check.
- Автотесты проверяют общестрой, сантехнику, электрику, дороги, ручные исключения,
  приоритет заполненной Формы №2 и вывод нескольких разрядов одной профессии.
