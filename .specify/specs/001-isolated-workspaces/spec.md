# Спецификация: изолированные рабочие пространства

**ID:** 001-isolated-workspaces  **Статус:** Approved  **Создана:** 2026-10-06

## Цель

Разделить работу admin, Насти и Кристины так, чтобы они не видели и не использовали файлы, карточки, чаты, задачи и пакеты друг друга.

## Пользовательские истории

- Как сотрудница, я вижу только свои карточки, файлы, сообщения и готовые пакеты.
- Как владелец, я управляю учётными записями без автоматического доступа к новым данным сотрудниц.
- Как пользователь, я не вижу размер и состав чужой очереди.

## Функциональные требования

1. Система ДОЛЖНА связывать новые карточки, журнал, задачи, загрузки и загрузочные ссылки с одной учётной записью.
2. Система ДОЛЖНА разделять браузерное сохранение по логину на одном компьютере.
3. Система ДОЛЖНА оставлять старые записи без владельца только в историческом пространстве admin.
4. Очередь ДОЛЖНА показывать пользователю только его собственную позицию; тяжёлая обработка остаётся последовательной для защиты сервера.
5. Очередь ДОЛЖНА чередовать учётные записи, чтобы одна серия файлов не блокировала остальных до конца серии.

## Вне скоупа

- Параллельный запуск нескольких тяжёлых OCR на текущем одном сервере.
- Разделение общих правил обучения ИИ.

## Критерии приёмки

- [x] Запись Насти нельзя получить под admin или Кристиной, и наоборот.
- [x] Старые неразмеченные записи доступны только admin.
- [x] Очередь не показывает количество чужих файлов.
- [x] При двух пользователях с очередями выбираются задания по очереди.
