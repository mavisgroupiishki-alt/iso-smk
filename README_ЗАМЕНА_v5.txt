ИИОФОРМИТЕЛЬ — ФИКС СТАЖА, ТРУДОВЫХ КНИЖЕК И АТТЕСТАТОВ (v5)

ЗАЧЕМ ЭТА ВЕРСИЯ
В версии v4 заполненные Формы №1–5 из корня архива превращались в обычный текст,
а затем часть данных отбрасывалась при обработке ИИ. Из-за этого могли исчезать:
- стаж по заявляемому виду деятельности;
- стаж у текущего юридического лица;
- номера трудовых книжек и все вкладыши;
- один из квалификационных аттестатов;
- ранее распознанные сведения человека при частичном ответе ИИ.

ЧТО ЗАМЕНИТЬ В GITHUB
1. Заменить index.html
2. Заменить server.py
3. Заменить generator_company_att_templates.py
4. Добавить новый файл company_attestation_source_parser.py в корень проекта

Файлы generator_company_att.py и classifier_company_att.json из v4 менять не нужно.

КАК ТЕПЕРЬ РАБОТАЕТ
- Уже заполненные Word-формы №1–5 читаются напрямую из таблиц DOCX.
- Стаж переносится дословно из Формы №2, без повторного расчёта ИИ.
- Трудовая книжка и все вкладыши объединяются по ФИО из Форм №2 и №3.
- Дипломы объединяются из Форм №2 и №4.
- Аттестаты объединяются из Форм №2 и №5; строка не удаляется, даже если номер
  присутствует только в полном тексте Формы №5.
- Частичный ответ ИИ больше не заменяет целиком список ИТР и не стирает поля.
- Структурированные данные исходных форм повторно накладываются после ответа ИИ,
  поэтому ИИ не может заменить точное значение на «—» или «0 дн.».

ПОСЛЕ ЗАМЕНЫ
1. Нажать Commit changes в GitHub.

5. Заново загрузить исходные заполненные Формы №1–5 или архив с ними.
6. Сформировать пакет.
