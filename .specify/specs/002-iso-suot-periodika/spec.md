# Спецификация периодики ISO / СУОТ

**ID:** 002-iso-suot-periodika  **Статус:** Approved  **Создана:** 2026-09-22

## Цель

По команде «периодика» формировать ежегодно актуализируемый пакет ISO, СУОТ или ISO+СУОТ из данных предыдущего пакета, а не повторно выдавать первичный комплект документов.

## Подтверждённая логика

Основание — архивы ISO «Дуотон», ISO «ПоланСтрой 2026», СУОТ «Дуотон» и СУОТ «ФэтСит».

- Периодика ISO включает переизданную политику, цели и ознакомление, реестр и план-отчёт рисков, внутренний аудит, оценку заказчиков с фактическими объектами, отчёт по процессу, график поверки, возможности, обучение/повышение квалификации и сводный отчёт СМК.
- Периодика СУОТ включает цели и ознакомление, план мероприятий по ОТ, учебно‑тренировочные мероприятия, SWOT, отчёт для анализа, программу и реестр рисков с актуальными картами, внутренний аудит.
- Постоянные руководства, процедуры, инструкции, журналы, стартовые приказы и должностные инструкции не переиздаются только из-за периодики.

## Пользовательские истории

- Как оформитель, я пишу «сделай периодику» и прикладываю прежний ISO/СУОТ пакет, чтобы карточка и новый пакет использовали сведения из архива.
- Как оформитель, я получаю только актуальные на новый период документы, а не полный первичный комплект.
- Как оформитель, я сохраняю выбранный тип ISO, СУОТ или ISO+СУОТ; слово «периодика» не превращает ISO в СУОТ и наоборот.

## Функциональные требования

1. Клиентское приложение ДОЛЖНО явно хранить режим `periodika` после соответствующей команды и передавать его при формировании.
2. Режим ДОЛЖЕН сохраняться при последующих уточнениях карточки и не менять выбранный стандарт ISO/СУОТ.
3. Генератор ДОЛЖЕН выбирать ежегодный состав по фиксированному списку документов для ISO и СУОТ.
4. При обычной генерации текущий полный состав пакета ДОЛЖЕН остаться без изменений.
5. Периодика ДОЛЖНА применять уже существующие фактические данные штата, объектов и поставщиков.
6. Если в периодике ISO есть отчёт об удовлетворённости заказчиков, он ДОЛЖЕН получать объекты из карточки.

## Вне скоупа

- Переписывание или копирование файлов прежнего архива в новый архив.
- Изменение шаблонов постоянных документов.
- Генерация документов без даты выезда, актуального штата или других обязательных данных карточки.

## Критерии приёмки

- [ ] Команда «сделай периодику» помечает карточку режимом периодики.
- [ ] Периодика ISO не содержит постоянные СТП, руководства, журналы, стартовые приказы и должностные инструкции.
- [ ] Периодика СУОТ не содержит руководство СУОТ, постоянные инструкции, журналы и стартовые приказы.
- [ ] Обычный ISO+СУОТ пакет продолжает содержать полный комплект.
- [ ] Объекты попадают в отчёт ISO по удовлетворённости заказчиков.
