# Исправление календаря: готовые задачи

В рабочем календаре и в колонке «Задачи без времени» больше не отображаются завершённые задачи.

Скрываются статусы:
- Готово
- Сделано
- Выполнено
- Завершено
- Закрыто

Задачи не удаляются из Supabase и остаются доступны во вкладке «Задачи», в проектах, статистике и истории.

Для этого обновления SQL выполнять не нужно. Достаточно заменить код приложения и выполнить новый Deploy в Render.
