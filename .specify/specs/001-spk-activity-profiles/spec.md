# Спецификация СПК профили деятельности

**ID:** 001-spk-activity-profiles  **Статус:** Approved  **Создана:** 2026-09-17

## Цель

Добавить в СПК отдельные корректные области деятельности, чтобы документы не содержали строительные формулировки там, где организация производит металлоконструкции или выполняет слаботочные работы.

## Пользовательские истории

- Как оформитель, я хочу выбрать «только производство металлоконструкций», чтобы пакет не содержал неподтверждённые СМР.
- Как оформитель, я хочу выбрать «СМР + производство металлоконструкций» по образцу «Металл комплект РБ», чтобы пакет использовал объединённую область.
- Как оформитель, я хочу выбрать «слаботочные системы», чтобы пакет использовал подтверждённый перечень электромонтажных и слаботочных работ из образца «ЭкспертПожПлюс».
- Как оформитель, я хочу, чтобы стандартный строительный пакет не изменился.

## Функциональные требования

1. Система ДОЛЖНА хранить отдельный профиль деятельности СПК, не меняя `spk_stroy` или `spk_bisp`.
2. Система ДОЛЖНА поддерживать профили `construction`, `metal_only`, `construction_metal` и `low_voltage_systems`.
3. Для `construction_metal` система ДОЛЖНА использовать формулировку образца «Металл комплект РБ».
4. Для `metal_only` система ДОЛЖНА использовать только производство и контроль металлоконструкций без неподтверждённых ссылок на СМР.
5. Для `low_voltage_systems` система ДОЛЖНА использовать подтверждённый перечень работ из «ЭкспертПожПлюс».
6. Система ДОЛЖНА изменить все затронутые приказ, обучение, протокол, положение и обязанности ИТР.
7. Система ДОЛЖНА сохранять персонал, СИ, ТТК, даты и макет документов.

## Вне скоупа

- Новые органы выдачи СПК.
- Автоматическое определение области без подтверждения оформителя.
- Создание новых ТТК, приборов, кадровых данных или нормативных актов.

## Критерии приёмки

- [ ] Каждый из четырёх профилей формирует пакет.
- [ ] Металл-only не содержит «строительно-монтажных работ» в заменяемых профильных разделах.
- [ ] Construction-metal содержит «производству строительных работ, производству металлоконструкций».
- [ ] Low-voltage содержит «монтажу слаботочных систем» и «видеонаблюдения».
- [ ] Construction сохраняет текущую формулировку.
- [ ] Изменённые DOCX визуально проверены.
