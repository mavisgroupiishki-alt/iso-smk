# ИИгорь Оформитель — Конституция

## Принципы

### I. Данные клиента защищены сервером
Каждый API-маршрут, который читает или изменяет данные клиента, ДОЛЖЕН проверять сессию и роль на сервере. Скрытие элементов интерфейса не считается контролем доступа.

### II. Минимальные привилегии
Оператор ДОЛЖЕН получать только доступ, необходимый для формирования новых пакетов. Сохранённые компании, общий журнал, база знаний и управление пользователями доступны только владельцу.

### III. Отзыв доступа действует сразу
Отключение пользователя ДОЛЖНО аннулировать его действующие сессии при следующем запросе. Пароли хранятся только в виде стойкого хеша.

### IV. Проверяемый результат важнее ответа ИИ
Приложение НЕ ДОЛЖНО сообщать, что файл прочитан, правка применена или пакет готов, пока это не подтверждено сохранённым результатом задачи и проверками. Неподтверждённые данные ДОЛЖНЫ быть отмечены источником и причиной проверки; они не могут подменяться предположением при формировании документов.

### V. Ограниченное ожидание
Разбор одного архива ДОЛЖЕН завершаться не позднее 30 минут с готовым результатом либо с перечнем конкретных непрочитанных файлов и страниц. Повторная попытка не должна бесконечно перезапускать всю работу или скрывать ранее прочитанные данные.

## Ограничения

- Без внешнего платного провайдера авторизации.
- Данные авторизации хранятся в Persistent Disk (`IGOR_DATA_DIR`).
- Начальный пароль владельца задаётся только через переменную окружения `IGOR_OWNER_PASSWORD`.
- Нельзя обещать предотвратить копирование файлов, уже скачанных пользователем.

## Рабочий процесс

- Новые маршруты и роли покрываются автоматическими проверками.
- Перед production-деплоем выполняется проверка аутентификации, авторизации и регрессий генератора.
- Перед заявлением об исправлении выполняются воспроизводимый тест и проверка затронутого сценария на контрольном архиве; если реальный внешний сервис не проверялся, это прямо указывается.

## Governance

Конституция имеет приоритет над реализацией. Изменение принципов требует изменения версии.
