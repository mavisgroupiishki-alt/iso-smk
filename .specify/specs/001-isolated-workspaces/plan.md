# Технический план: изолированные рабочие пространства

**Спека:** [spec.md](spec.md)  **Создан:** 2026-10-06

## Архитектура

Каждый API-запрос получает пользователя из сессии. Сервер применяет его id как область доступа для KV, карточек, журнала, задач и скачиваний. Локальные ключи браузера получают префикс логина. Очередь остаётся одной из-за лимита памяти, но выбирает следующую учётную запись по кругу и выдаёт только локальную позицию.

## Риски

- Старые записи не имеют владельца. Они не перемещаются и доступны только admin.
- Одновременный OCR нельзя безопасно включить без отдельных worker-ресурсов.

## Проверка конституции

- [x] Изоляция проверяется через HTTP/API и функции доступа.
- [x] Исторические данные не удаляются.
- [x] Очередь остаётся ограниченной одним OCR.
