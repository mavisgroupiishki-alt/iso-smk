# Спецификация: Отзывной доступ сотрудницы

**ID:** 001-revocable-operator-access
**Статус:** Approved
**Создана:** 2026-09-15

## Цель

Дать сотруднице отдельный доступ только для формирования новых пакетов и позволить владельцу немедленно отозвать этот доступ.

## Пользовательские истории

- Как владелец, я хочу войти в приложение под своей учётной записью и управлять учётной записью сотрудницы.
- Как сотрудница, я хочу начать новый пакет, загрузить документы, сформировать и скачать результат.
- Как владелец, я хочу отключить сотрудницу так, чтобы её открытая сессия сразу перестала работать.
- Как сотрудница, я не хочу видеть сохранённые компании, общий журнал, старые архивы или базу знаний.

## Функциональные требования

1. Приложение ДОЛЖНО требовать входа по логину и паролю.
2. ДОЛЖНЫ существовать роли `owner` и `operator`.
3. Владелец ДОЛЖЕН создавать, менять пароль, отключать и удалять оператора.
4. Оператор ДОЛЖЕН работать только с новым пакетом в текущей сессии: загрузка, ИИ-чат, формирование, скачивание своего результата.
5. Оператор НЕ ДОЛЖЕН получать через интерфейс или API сохранённые компании, общий журнал, старые ZIP-архивы, базу знаний, настройки или учётные записи.
6. Результат, задача обработки и ZIP ДОЛЖНЫ быть привязаны к пользователю, который их создал.
7. Отключённый или удалённый оператор НЕ ДОЛЖЕН продолжать пользоваться уже открытой сессией.
8. Пароли ДОЛЖНЫ храниться только как стойкие хеши, а сессии — в защищённых HTTP-only cookie.
9. Начальный пароль владельца ДОЛЖЕН задаваться через `IGOR_OWNER_PASSWORD` в Render, а не в коде или чате.

## Вне скоупа

- Предотвращение скриншотов или сохранения ZIP, уже доступного сотруднице.
- Многофакторная аутентификация, почтовые приглашения и восстановление пароля.
- Ведение отдельной клиентской базы для оператора.

## Критерии приёмки

- [ ] Незалогиненный запрос к защищённому API получает 401.
- [ ] Оператор может пройти полный путь нового пакета и скачать только собственный результат.
- [ ] Оператор получает 403 для компаний, базы знаний, общего журнала, управления пользователями и чужих задач/ZIP.
- [ ] После отключения оператора его следующий запрос получает 401.
- [ ] Владелец может создать, сменить пароль, отключить и удалить оператора.
