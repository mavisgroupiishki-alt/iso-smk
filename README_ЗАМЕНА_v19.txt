ИИГОРЬ v19 — три критичных исправления по тестам

Заменить в GitHub:
- index.html
- server.py
- generator_iso_suot_templates.py

1. ISO/СУОТ — должностные и рабочие инструкции
- Если штатная должность известна, ИИгорь больше не пишет «дополнить профильными обязанностями».
- Для финансовых/экономических, бухгалтерских, снабженческих, кадровых, юридических,
  сметных, инженерных, производственных и других ролей добавлены профильные обязанности.
- Для рабочих профессий добавлены профильные требования ОТ по типу работ.
- Жёлтый маркер остаётся только если сама должность/профессия не определена.

2. ISO — карточки поставщиков
- Карточка снова строится в структуре исходного утверждённого шаблона:
  Пц, Пк, Поп, Пуп, Пуо, Пи, Пстп, сумма, основной/приемлемый.
- Название поставщика и поставляемая продукция берутся из фактического перечня клиента.
- Фиктивный конкурент не создаётся.
- Баллы не выдумываются. Если фактической оценки нет, вместо десятка жёлтых клеток
  остаётся один компактный пункт на проверку.

3. Аттестация / СПК — большие трудовые и сканы
- Большой PDF >5 МБ автоматически отправляется в фоновую обработку, пользователю
  не нужно вручную разбивать файл.
- Трудовые книжки читаются до 40 страниц.
- PDF внутри ZIP допускается до 80 МБ.
- Большая трудовая не читается дважды целиком: это сокращает число vision-вызовов
  почти вдвое и уменьшает риск таймаута.
- Тяжёлые PDF обрабатываются по одному, чтобы Render 512 МБ не падал по памяти.
- Фото с телефона >3 МБ автоматически уменьшаются в браузере перед отправкой.
