# Изменения версии «Проекты и переносы»

## Реализовано

- Полная иерархия: проект → этап → задача.
- Создание и редактирование проектов.
- Создание и редактирование этапов.
- Привязка задач к проектам и этапам.
- Раскрывающийся интерфейс по образцу Google-таблицы.
- Автоматический прогресс этапов и проектов.
- Новые статусы «Ожидает» и «Блокер».
- Поле рабочего комментария в задаче.
- Отдельная вкладка истории переносов.
- Автоматическая фиксация старой и новой даты дедлайна.
- Фиксация даты и времени переноса, автора и причины.
- Отдельный список задач, перенесённых с текущей недели.
- Отдельный фильтр задач, перенесённых на следующую неделю.
- Счётчик переносов в верхней части дашборда.
- Предупреждение о переносах с текущей недели.
- Создание и безопасное удаление сотрудников.
- Импорт проекта и этапов из Excel.
- Обновлённая цветная навигация и карточки.
- Сохранены календарь, список задач и график загрузки.

## Файл обновления базы

```text
supabase_projects_update.sql
```

Его необходимо выполнить один раз в SQL Editor существующего проекта Supabase.


## Комментарии и ссылки в задачах

- В каждой задаче есть отдельное поле «Комментарий» для хода работы, договорённостей, результата и блокеров.
- Добавлено отдельное поле «Ссылка на материалы».
- Поддерживаются Google Sheets, Google Docs, Google Drive, Miro и любые ссылки по HTTP/HTTPS.
- Ссылка отображается как кликабельная кнопка в проекте и в общем списке задач.
- Старые ссылки, уже записанные в комментариях, можно автоматически вынести в отдельное поле с помощью `supabase_task_links_update.sql`.

## Версия «Календарь с перетаскиванием»

- Задачи в календаре можно перетаскивать между днями и временными слотами.
- Добавлена боковая колонка всех задач без времени.
- Задачу без времени можно сразу поставить на нужный день и час.
- Задачу из календаря можно перетащить в блок «Снять время с задачи».
- Шаг планирования — 30 минут.
- При переносе на другой день запись автоматически попадает в историю переносов.
- Перемещение сохраняется непосредственно в Supabase.
- При ошибке сохранения интерфейс откатывает задачу на прежнее место.
- Перед календарным переносом создаётся локальная страховочная копия.
- Добавлена выгрузка полной резервной копии данных в JSON.
- Исправлена защита локальной копии от перезаписи пустыми данными при запуске.
- Изменений структуры базы нет; SQL запускать не требуется.

## Фильтры, разделы и заказчик проекта

- Добавлен единый фильтр по конкретной дате, неделе и месяцу для проектов, разделов, списка задач и календаря.
- Добавлена вкладка «Разделы» для задач, которые не относятся к проектам.
- Разделы можно создавать, редактировать и удалять; у раздела есть ответственный, описание и цвет.
- Задача может находиться либо в проекте/этапе, либо в разделе.
- В карточке проекта сохранено поле ответственного и добавлено поле заказчика.
- Миграция `supabase_hierarchy_sections_update.sql` не удаляет и не перезаписывает существующие данные.

## Иерархия разделов — август 2026

- Раздел теперь содержит проекты, проекты содержат этапы, этапы содержат задачи.
- Проект можно перенести в раздел из формы или прямо из карточки.
- В каждом разделе добавлен собственный фильтр статусов задач.
- По умолчанию внутри разделов скрыты готовые задачи.
- Проекты и задачи без привязки не удаляются, а отображаются в специальных блоках.
- График загрузки переведён с часов на количество активных задач.
- В карточке сотрудника основным показателем стало количество активных задач.
- Добавлена постоянная кнопка «Сбросить все фильтры».
