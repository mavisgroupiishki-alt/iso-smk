ИИГОРЬ — ПОЛНЫЙ ПРОЕКТ, НАКОПИТЕЛЬНАЯ ВЕРСИЯ V14

Это полный проект, собранный из исходного репозитория и всех последовательных
исправлений до v14 включительно:
- аттестация компании и специалиста;
- стандартные рабочие по видам работ;
- самостоятельный расчёт стажа;
- жёлтое выделение сомнительных/пустых данных внутри документов;
- ISO 9001 и СУОТ;
- СПК Стройкомплекс и БИСП;
- универсальный разбор архивов, Word, PDF, XLS и XLSX;
- постоянные карточки компаний;
- вкладка «Знания ИИгоря»;
- вкладка «Расчёт стажа».

КАК ВОССТАНОВИТЬ GITHUB

1. Распакуйте архив.
2. Создайте новый пустой репозиторий GitHub.
3. Загрузите В САМ КОРЕНЬ репозитория всё содержимое этой папки:
   Procfile, server.py, generator.py, index.html, render.yaml, requirements.txt
   и все папки с шаблонами.
4. Не загружайте внешнюю папку поверх проекта как дополнительный уровень.
   В корне GitHub должен сразу лежать файл server.py.
5. Сделайте Commit changes.

RENDER

Build command:
  pip install -r requirements.txt

Start command:
  python server.py

Переменная окружения:
  VIBE_API_KEY=<ваш действующий ключ>

Для общей базы компаний и знаний после перезапусков нужен Persistent Disk.
Mount path:
  /data

Переменная:
  IGOR_DATA_DIR=/data
