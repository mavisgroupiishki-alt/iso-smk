# MAVIS Task Tracker 6.0

Иерархия: **Раздел → Проект → Этап → Задача**.

Версия 6.0 добавляет:

- авторизацию сотрудников по логину и паролю;
- администратора Аню;
- регистрацию сотрудников из вкладки «Команда»;
- индивидуальную норму активных задач;
- подсветку перегруза;
- график активных задач относительно нормы;
- фильтры по разделу, приоритету, заказчику и статусу;
- архив и шаблоны проектов;
- массовое изменение задач.

Главная инструкция: `ОБНОВЛЕНИЕ_6_0_АВТОРИЗАЦИЯ.md`.
