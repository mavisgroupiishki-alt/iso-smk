ИСПРАВЛЕНИЕ V13 — СОХРАНЕНИЕ ПОЛНОЙ КАРТОЧКИ КОМПАНИИ

Заменить в GitHub:
1. index.html
2. server.py
3. render.yaml

Что исправлено:
- вкладка «Компании» теперь использует полные карточки ИИгоря, а не старую сокращённую форму;
- сохраняются ВСЕ структурированные данные: реквизиты, директор, сотрудники/ИТР,
  рабочие, объекты, поставщики, виды работ, удостоверения, СПК-данные,
  средства измерений, поверки, ТТК, оборудование, помещения и список исходных документов;
- данные сначала синхронно сохраняются в localStorage браузера, поэтому закрытие вкладки
  больше не обнуляет карточку;
- затем данные синхронизируются с сервером;
- сохранение выполняется каждые 12 секунд, после каждого обновления карточки,
  при сворачивании/скрытии и перед закрытием страницы;
- карточка получает стабильный ID и не дублируется при исправлении названия или УНП;
- частичный ответ ИИ больше не стирает остальные сотрудники, объекты, поставщиков и СПК-данные;
- JSON на сервере записывается атомарно и не повреждается при перезапуске;
- исправлено ложное обозначение успешно прочитанного Excel «[Лист: ...]» как ошибки;
- Render теперь устанавливает зависимости из requirements.txt.

ВАЖНО ПРО RENDER:
- localStorage сохраняет данные в том же браузере даже без Render Disk;
- для общего реестра, доступного всем экспертам с разных компьютеров, подключите
  Render Persistent Disk и смонтируйте его в /data. В render.yaml уже указан IGOR_DATA_DIR=/data.
- без Persistent Disk серверная копия может исчезнуть после deploy/restart, но локальная
  копия в браузере останется.
