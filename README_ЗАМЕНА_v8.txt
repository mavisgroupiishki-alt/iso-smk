ЧТО ИЗМЕНЕНО

1. СТАЖ БОЛЬШЕ НЕ БЕРЁТСЯ ИЗ ГОТОВОЙ ФОРМЫ №2

Значения из ранее заполненной Формы №2 сохраняются только как справочная сверка.
В Форму №2 нового пакета подставляется только результат расчёта по записям трудовой книжки и вкладышей.

2. СИСТЕМА САМА СЧИТАЕТ СТАЖ

ИИ извлекает из трудовой каждую запись в employment_periods:
- точную дату приёма;
- точную дату увольнения;
- должность;
- организацию;
- признак текущего работодателя;
- уверенность распознавания.

Сервер, а не ИИ:
- отбирает периоды по заявляемой специализации;
- исключает рабочие профессии из стажа ИТР;
- не считает обычную запись «Директор» стажем главного инженера/прораба без явного перевода или совмещения;
- объединяет пересекающиеся периоды, чтобы один день не считался дважды;
- считает отдельно общий стаж и стаж в текущей организации;
- для открытой записи использует дату формирования пакета;
- переводит итог по правилу 30 дней = 1 месяц, 12 месяцев = 1 год.

Система не придумывает 01.01, если в трудовой виден только год или неполная дата.

3. ДЛИННЫЕ ТРУДОВЫЕ PDF

Для PDF, в названии которых есть «трудовая», «вкладыш» и аналогичные обозначения,
обрабатывается до 24 страниц, а не только первые 3. Страницы отправляются на распознавание партиями.
Если документ длиннее лимита или отдельная партия не распозналась, система сохраняет предупреждение,
а связанные данные и стаж помечает для жёлтой проверки.

4. ЖЁЛТОЕ ВЫДЕЛЕНИЕ

В сформированных Word-документах жёлтым выделяются:
- отсутствующие поля;
- неполные или неразборчивые даты;
- значения с низкой уверенностью распознавания;
- конфликтующие сведения из разных документов;
- стаж, рассчитанный только по подтверждённому минимуму при наличии сомнительных периодов;
- пустые реквизиты, дипломы, трудовые книжки, аттестаты, виды работ, рабочие и даты подписания.

Пакет формируется даже при наличии таких данных. Жёлтый цвет означает: поле нужно проверить перед подачей.

ВАЖНО ПО СТАРЫМ КАРТОЧКАМ

Старые версии могли сохранить только готовый итог стажа и потерять хронологию трудовой.
После обновления для существующей карточки один раз повторно загрузите трудовые книжки и вкладыши
либо создайте новую карточку. Без исходных периодов система намеренно не подставит готовый стаж из Формы №2.
