Что исправлено:

1. Аттестация компании — данные ИТР / стаж / трудовые
Частичный ответ ИИ больше не может стереть уже распознанные дипломы,
трудовые книжки, вкладыши, аттестаты и периоды работы пустыми значениями.
При формировании данные карточки сотрудника объединяются с данными аттестации
без потери заполненных полей. Стаж по-прежнему считается по трудовой.

2. СПК — ошибки по людям
ФИО и должность одного человека сохраняются вместе.
Из Справки ИТР убрано выдумывание «Протокол №1» и даты пакета:
номер/дата берутся только из реального документа сотрудника.
Частичный ответ ИИ не обнуляет ранее найденные сведения человека.

3. СПК — Справка СИ / поверки / калибровки
В промпт добавлено обязательное структурирование:
- приборы -> measurement_tools;
- поверки -> verification_documents;
- калибровки -> calibration_documents.
Сопоставление прежде всего по заводскому номеру, затем по модели/названию.
Массивы СПК теперь объединяются, а не заменяются неполным последующим ответом.

4. ISO + СУОТ — приказы с неправильными ФИО/должностями
Приказы, в которых назначаются сотрудники, больше не копируются из «Варты».
Они формируются заново по текущей карточке компании:
каждый человек выводится со своей фактической должностью и ФИО.
Это применяется к аудиторам, группе рисков, владельцу процесса,
ответственному за документы, координационному совету, обучению,
входному контролю, СИ и ключевым приказам СУОТ.

5. ISO — оценка поставщика
В карточке теперь всегда есть отдельный блок «Сведения об оценке поставщика».
Если фактические баллы есть — они выводятся.
Если баллов нет — ИИгорь их не выдумывает, а оставляет один понятный пункт
на проверку вместо пустой/непонятной карточки.

6. СПК — ТТК
Убраны вымышленные ТТК-001 / ТТК-002 и «Стройтехнорм».
Справка строится по реальным данным spk.ttk.
Если исходных данных нет — это явно отмечается как требующее уточнения.

7. Не все файлы считываются
Сохранены улучшения v19 для больших трудовых.
Дополнительно для обычных сканированных PDF добавлен повторный способ чтения,
если первая попытка вернула пустой результат.
